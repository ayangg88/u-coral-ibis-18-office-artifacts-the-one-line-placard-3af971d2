One line, at most 180 characters, labelling an ordinary office object as an ancient artifact. This entry is a museum placard for a stapler, written as if it were a ritual binding device dug from a lost civilisation — catalogue date, material, and donor included, in a dry curator's voice.

## The placard

> Ritual binding device, c. 1994. Steel and plastic. Used to fasten two sheets in eternal union; divorce required the sacred remover. Gift of the Accounts Department.

## Run

```sh
python3 main.py
# writes the placard to /output/entry.txt
```

## Entry

`main.py` (stdlib only) writes the single placard line to `/output/entry.txt`. No network, no secrets, deterministic.
